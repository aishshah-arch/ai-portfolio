# Aishwarya Shah | AI Portfolio

Professional portfolio for the M.S. in Artificial Intelligence program at Indiana Wesleyan University.

Live site: https://aishshah-arch.github.io/ai-portfolio/

## Structure

- `index.html`: Professional Bio, Personal Value Proposition, artifact gallery, other work, contact
- `artifacts/artifact-1.html` to `artifact-5.html`: one page per required artifact, pre-built with every required section
- `artifacts/assets/`: screenshots, PDFs, and other deliverable files
- `style.css`: shared styles

## Adding an artifact

1. Put the deliverable files (screenshots, PDF, etc.) in `artifacts/assets/`.
2. Open `artifacts/artifact-N.html`, set the title and course line, and replace each placeholder box with your content. Uncomment the example image, download, or code link in the Deliverable section.
3. In `index.html`, update that artifact's card: title, one-line summary, and change `status soon` / "In progress" to `status done` / "Completed".
4. Commit and push. GitHub Pages updates in about a minute.

Reflections go in Brightspace, not on this site.
